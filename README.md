# DDS Fusion Lab

An offline-friendly, single-page companion for Yu-Gi-Oh! Dark Duel Stories. It includes a starter deck hand solver, fusion lookup, and alignment reference.

The app is self-contained in `index.html`. It needs no build step, dependencies, or backend.

## GitHub Pages

Publish the repository's `main` branch from the root directory in **Settings → Pages**. The site URL will be `https://<username>.github.io/dds-fusion-lab/` for a repository named `dds-fusion-lab`.

The fusion database covers verified starter-focused recipes rather than every fusion in the game.
